5、什么叫长连接？什么叫短连接？（参考面试宝典）
```
长连接: 一次连接 多次任务. 避免反复创建的连接导致的资源消耗
短连接: 一次连接 一次任务. 避免长期占用连接资源
```

3、解释以下名词含义，并说明其作用

• IP
```
Internet Protocol. 网络地址. 用于网络寻址, 路由连接.
```

• port
```
端口. IP + 端口就可以绑定确定的套接字(socket)
端口在传输层会用到. 不同的协议, 都有独立的端口
```

• 子网掩码（如何通过子网掩码制订当前网络下最多连多少台主机）
```
现代网络IP 就是通过CIDR/子网掩码, 来区分网络位 + 主机位.
当前网络主机数: 2^32-mask - 2
减2 一个是 网络地址 一个是 广播地址.
```

• DNS服务器
```
域名 转成对应的IP
```

• DHCP服务器
```
动态主机配置协议
自动分配局域网下的主机地址. 不用手动配置.
```

• 广播与组播
```
广播:当前局域网下全都通知一遍, 不管你接不接收
组播:加入组的成员才会被通知.
```

2、简述任意两种并发服务器的设计，并说明其优缺点以及容易出现的问题
```

```
