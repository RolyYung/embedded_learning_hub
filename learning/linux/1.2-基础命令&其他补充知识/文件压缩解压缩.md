# tar

> linux自带的tar文件归档工具\. 默认并没有压缩, 只是简单的把文件archive当一个目录文件下\.
> 
> 

tar 起源于 tape archive\. 磁带归档\. 是老Unix系统延续下来的\. 

tar 命令开头就是说我要对文件进行归档了 至于是压缩 还是解压缩, 还是查看压缩文件, 看命令后面带的参数



## 压缩

```Bash
tar -cf target.tar source1.txt source2 source3.c
```

\-c: 创建一个归档文件

\-f: 指定文件名, 如果没有这个文件名, 默认会有一个Tape文件夹\.但是也看具体发行版实现

所以不要忘记\-f参数, 不然很大概率会报错\.



## 解压缩

```Bash
tar -xf target.tar
```

> 注意解压缩 如果目录下有同名的文件/目录 原来的会被覆盖\.
> 
> 



## 压缩算法

### gz

```Bash
tar -czf target.tar.gz FILE...
```

gzip 一种压缩格式, 如果后续想深入等项目上用到了再说



### bzip2

```Bash
tar -cjf target.tar.bzip2 FILE...
```

bzip2也是一种压缩格式\.
