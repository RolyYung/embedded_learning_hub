# cd

change directory, 切换目录

## 常用操作

1. 回到用户主目录,cd 命令后没有任何参数和选项

```Shell
cd
```

2. 回到上级目录

```Shell
cd ..
```

3. 切换回上次的目录: \-

```Shell
cd -
```

# touch

创建文件 / 修改已存在文件的日期

注意只是文件操作\.只会创建一个文件, 不能创建目录, 同时如果存在同名目录, 那么会修改目录时间戳, 而不是会新建一个同名的文件

1. 创建文件

```Shell
touch hello.c
```



2. \-d 短选项

```Shell
touch -d "08-27" hello.c // 修改hello.c文件日期. 或者新建hello.c文件, 修改日期为08-27
```



# rm

```Shell
rm [选项] [目录/文件名]
```

\-rf

> r: recursive 递归删除\. 删除目标目录的子目录 \& 子文件
> 
> f: force 强制的, 专注的\. 不需要过多询问以及不影响的报错也不需要提示
> 
> 

示例场景:

```Shell
rm hello.c // hello.c 如果不存在, 终端会提示: No such file or directory
```

```Shell
rm -f hello.c // 这个终端就不会提示
```

# shutdown

关闭电源\. 关机

```Shell
shutdown [选项] [时间]
```

## 选项

1. \-r

reboot/restart: 重启

```Shell
shutdown -r now // 现在重启, now是特殊关键字, 只有shutdown才能理解
shurdown -r
shutdown -r +10 // 十分钟后重启
shurdown -r 20:30 // 晚上八点钟三十分重启
```



2. \-h

halt: 停止

平时我们理解的停止是stop, halt是更官方, 更命令式的停止\.

如: 军队的"立定"口令; 警察的命令嫌疑犯\.

```Shell
shutdown -h now
shutdown -h +10
shutdown -h 20:30
```



# reboot

重启计算机\.

相比于我们平时的restart, reboot更偏向于技术, reboot中的boot 原本指向的是bootstrap\(引导程序\)\.早期计算机的概念 已知沿用到现在\.





# 通配符

## \*

匹配任意字符

```Shell
*.txt // 匹配后缀为.txt的所有文件
```



## ?

匹配单个字符

```Shell
?.c // 匹配单名的.c文件
```



## \[\] 

匹配括号内的单个字符就可

```Shell
hell[a-z].c // 不管是hello.c 还是halla.c都可以匹配到
```



## 进阶组合使用

```Shell
*_[a-z]_*_[0-9].c
```

可以匹配到匹配 direct\_a\_source\_1\.c

匹配不到direct\.c文件
