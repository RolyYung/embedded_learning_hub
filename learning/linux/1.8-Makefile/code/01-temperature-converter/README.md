# 项目 1：温度转换器

程序入口是 `main.c`，支持摄氏度和华氏度互转。

## 基础任务

1. 创建自己的 `Makefile`，默认构建目标文件名为 `temperature`。
2. 使用变量保存编译器、编译选项和目标文件名。
3. 提供默认构建目标、`run` 和 `clean` 目标。
4. 将不代表真实文件的目标声明为伪目标。

## 改进任务

1. 在编译命令中使用 `$@` 和 `$<`，不要重复写目标名和源文件名。
2. 开启常见警告，并使用 C11 标准。
3. 让 `run` 目标构建完成后执行一次 `c2f 100`。

## 挑战任务

增加一个 `help` 目标，简要列出可用目标，但不要让它成为默认目标。

## 验收

- 默认构建后生成 `temperature`。
- 运行 `./temperature c2f 100`，应输出 `100.00 C = 212.00 F`。
- 连续构建两次，第二次不应重新编译。
- 清理后，可执行文件应消失，源码应保留。

## 本项目知识点

目标、依赖、命令、默认目标、变量、伪目标、`$@`、`$<`。
