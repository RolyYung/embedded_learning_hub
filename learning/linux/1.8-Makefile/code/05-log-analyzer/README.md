# 项目 5：Debug/Release 日志分析器

该项目需要支持两种构建模式，默认模式由你决定。不同模式的产物必须相互隔离。

## 基础任务

1. 接受命令行传入的构建模式变量，仅允许 `debug` 和 `release`。
2. Debug 使用适合调试的选项并定义 `ENABLE_TRACE`。
3. Release 使用优化选项并关闭断言。
4. 使用编译宏给字符串宏 `BUILD_MODE` 传入当前模式。
5. 分别输出到 `build/debug/` 和 `build/release/`。

## 改进任务

1. 分别练习递归展开变量、立即展开变量、条件赋值和追加赋值，记录它们的区别。
2. 编译规则使用 `$@`、`$<`，链接规则使用 `$@`、`$^`。
3. 增加 `debug`、`release`、`run`、`clean`、`print-config` 目标。
4. 输入不支持的模式时，在开始编译前给出清晰错误。

## 挑战任务

1. 从命令行覆盖编译器或追加警告选项，确保用户传入值不会被无意覆盖。
2. 让 `print-config` 显示最终生效的模式、编译选项、预处理宏和输出目录。
3. 研究命令回显和静默执行，只对创建目录、删除文件等辅助命令隐藏回显。

## 验收

- Debug 输出中包含 `TRACE` 行，Release 输出中不包含。
- 程序能打印正确的构建模式和 `INFO=2 WARN=1 ERROR=2`。
- 两种模式可以同时存在，切换模式不会错误复用另一模式的对象文件。
- 非法模式立即失败，并提供可理解的错误信息。

## 本项目知识点

变量赋值方式、命令行覆盖、条件判断、预处理宏、多配置输出、自动变量、错误处理。
