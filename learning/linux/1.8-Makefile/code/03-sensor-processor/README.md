# 项目 3：传感器数据处理器

源码位于 `src/`，头文件位于 `include/`。所有构建产物必须放进由你创建的 `build/`，不要污染源码目录。

## 基础任务

1. 自动收集 `src/` 下的所有 `.c` 文件。
2. 根据源文件列表推导出 `build/` 下对应的 `.o` 文件列表。
3. 使用一条模式规则完成全部对象文件的编译。
4. 构建前自动创建输出目录，最终生成 `build/sensor_processor`。

## 改进任务

1. 模式规则中正确使用 `$@` 和 `$<`。
2. 链接规则中正确使用 `$@` 和 `$^`。
3. 新增一个源文件时，应只修改 C 代码，不需要手工修改对象文件列表。
4. 研究“普通依赖”和“仅保证执行顺序的依赖”的区别，避免仅因目录时间戳变化就重编译对象文件。

## 挑战任务

增加 `print-vars` 目标，显示你推导出的源文件列表和对象文件列表，用它检查路径转换是否正确。

## 验收

- 所有 `.o` 和可执行文件都位于 `build/`。
- 程序输出 5 个样本和平均温度 `23.80 C`。
- 新增同结构的 `.c` 文件后，构建系统能自动发现它。
- 第二次构建无多余命令；修改单个 `.c` 时只重编译对应对象文件。

## 本项目知识点

通配文件、文本替换、模式规则、目录创建、路径映射、自动变量、增量构建。
