# 项目 2：学生成绩系统

该项目由 3 个源文件和 2 个头文件组成，编译时需要添加 `include/` 头文件搜索路径。

## 基础任务

1. 分别把每个 `.c` 编译成同名 `.o`，再链接为 `student_manager`。
2. 明确写出正确的源文件和头文件依赖。
3. 使用变量集中保存编译器、编译选项、对象文件和目标名。
4. 提供 `all`、`run`、`clean` 目标。

## 改进任务

1. 对象文件编译规则中使用 `$@` 和 `$<`。
2. 最终链接规则中使用 `$@` 和 `$^`。
3. 对比 `$<` 与 `$^` 在链接规则中的展开结果，思考为什么其中一个不适合表示全部对象文件。

## 挑战任务

做以下增量编译实验，并解释结果：

1. 只修改 `student.c`。
2. 只修改 `include/student.h`。
3. 只修改 `include/report.h`。

## 验收

- 程序能输出四名学生、平均分和最高分。
- 修改一个实现文件时，只重新编译受影响的对象文件，然后重新链接。
- 修改头文件时，所有直接或间接包含它的源文件都应按依赖关系重新编译。
- 无修改时再次构建，不执行编译或链接命令。

## 本项目知识点

分离编译、链接、头文件依赖、增量构建、变量、`-I`、`$@`、`$<`、`$^`。
