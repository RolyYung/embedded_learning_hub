# Makefile 渐进练习项目

这里包含 6 个 C 语言项目，但**故意不提供 Makefile 和参考答案**。你的任务是根据每个项目的 `README.md`，从零编写 Makefile。

## 学习顺序

1. `01-temperature-converter`：单文件程序与基本目标
2. `02-student-manager`：多文件编译、头文件依赖与自动变量
3. `03-sensor-processor`：目录管理、模式规则与源文件发现
4. `04-static-library-calculator`：静态库的创建与链接
5. `05-log-analyzer`：Debug/Release 构建与变量控制
6. `06-device-simulator`：自动依赖、测试和综合构建

## 必须掌握的自动变量

- `$@`：当前规则的目标
- `$<`：当前规则的第一个依赖
- `$^`：当前规则的全部依赖（重复项只保留一次）

练习说明会指出应当使用哪类知识，但不会给出可直接复制的规则。

## 建议学习方法

每完成一个阶段，先运行程序验证结果，再做增量编译实验：连续执行两次构建、只修改一个 `.c` 文件、只修改一个 `.h` 文件，观察实际执行的命令是否合理。

当你需要检查时，可以把自己写的 Makefile 交给我。我会先指出问题和给出提示；除非你明确要求，否则不会直接提供完整答案。
