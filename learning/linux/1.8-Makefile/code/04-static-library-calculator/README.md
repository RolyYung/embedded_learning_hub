# 项目 4：静态库计算工具

将 `lib/` 中的实现编译并归档为静态库，再让 `app/main.c` 链接该库。构建产物统一放在 `build/`。

## 基础任务

1. 将 `lib/` 下的源文件分别编译为对象文件。
2. 使用静态库归档工具生成 `build/libcalc.a`。
3. 编译应用对象文件并链接为 `build/calculator`。
4. 提供 `all`、`run`、`clean` 和 `distclean` 目标，并自行规定两种清理目标的区别。

## 改进任务

1. 编译规则使用 `$@` 和 `$<`。
2. 归档规则和最终链接规则使用 `$@`、`$^`。
3. 将归档工具及其选项也定义为变量。
4. 观察链接命令中对象文件和静态库的位置；尝试交换顺序，记录结果并解释原因。

## 挑战任务

新增一个 `show-library` 目标，用归档工具列出静态库包含的成员，但不要解包静态库。

## 验收

- `build/libcalc.a` 中应包含三个库对象文件。
- 应用输出加、减、乘三项计算结果。
- 修改 `lib/add.c` 后，只重编译相应对象、更新静态库并重新链接应用。
- 修改 `app/main.c` 后，不应重建静态库。

## 本项目知识点

静态库、归档工具、模式规则、链接顺序、多级依赖、`$@`、`$<`、`$^`。
