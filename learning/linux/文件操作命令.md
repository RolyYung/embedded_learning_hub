# 文件操作命令

# cat

> concatnate 连接串联的意思
> 
> 

```Bash
cat 1.txt // 输出1.txt的文本内容到终端
cat 1.txt 2.txt //输出1.txt 2.txt的文本内容到终端
```

把文件内容合并起来,输出到终端中去\.

如果只有一个文件, 那就是展示文件的文本内容了\.



常用的选项:

\-n \-\-number=n: 展示行数\.



# tail

> 展示文件尾部的文本内容
> 
> 



```Bash
tail -5 hello.c
```

展示hello\.c文件的最后五行文本\.



常用options:

1. \-n : n是具体的数字, 就会展示最后几行文本

2. \-f: follow 追踪最新的文本变化, 实时展示\.

用vim编辑保存的文件不会被追踪到 因为vim会覆盖掉原来的文件, 新建一个临时文件覆盖的\. 



# head

```Bash
head -10 hello.c //查看hello.c的前十行内容
```



# echo

> 终端输出字符串or变量
> 
> 

echo在英文中的意思是"回响"的意思\. 在linux 终端命令中就是"回显"的意思\.

意思是在echo后面给什么, 终端就显示什么\.

我的理解: 类似C语言中的printf, js的console\.log, 给什么就显示什么

## 例子

```Bash
echo hello world //终端输出hello wolrd
echo "hello world" // 终端输出hello world
```

虽然这个例子显示的都是一样的, 只是巧合\. 第一个命令输入两个参数, 第二命令只输入了一个参数\. 只是在echo展示时,用空格分隔展示了两个参数\.

## ? 终端中什么是变量

例子:

```Bash
name=roly // 在当前这个终端中定义一个变量 值为roly
echo $name // roly
```

有些环境变量是$HOME, $PATH, 在所有终端都可以访问到\.

# 重定向: \>;\>\>

## '\>'覆盖文件

理解: 原本你的echo "hello"命令会输出hello到终端\(终端也是一个文件\)

后面你的加上'\>'重定向符了, \`echo hello \> 1\.txt\`那么就会输出到1\.txt中去, 如果1\.txt文件中有内容就会覆盖

## '\>\>'在文件尾部追加 append

理解了'\>'就好理解了'\>\>',这重定向的基础上不破坏原本的文本内容,而是在尾部增加, 所以也就是追加的作用\.





# grep

> 在指定文件中查找指定字符串
> 
> 

```Bash
grep -R "hello" ./hello.c
```

\-R: 解引用递归查找\.

\-i: 忽略\(ignore\)大小写, 查找\.



grep: g/re/p

global: 全局

re: regular expression 正则表达式

p: print

> 全局用正则表达式搜索文本内容, 并打印出来
> 
> 

如果没有正则表达式, 那就会按照简单的字符串搜索\.



# 管道\(\|\)

> 将前一个命令的输出转到后一个命令的输入
> 
> 

```Bash
echo "hello" | grep 'o'
```

在hello中找字符'o'



# find

```Bash
find ./ -name "*.txt"
find ./ -type f // f是文件, d是目录
```

这里的\-name \-type 不是严格意义上的选项, 而是test\(判断条件\)\.

如果你单纯地用find \.就和ls \-R差不多作用\. 

ls主要是展示,find是遍历找到你要的文件, 展示起来还是会不一样的\.





# chmod

> 修改文件权限
> 
> 

```Bash
chmod u=rwx 1.txt // 将1.txt文件的用户权限改成可读可写可执行.
```



# cut

```Bash
cut -d ":" -f 1,3 hello.c
```

> hello\.c中每行进行裁剪, 以:为分隔符, 取才出来的第一个和第三个字段
> 
> 



# chown

> 顾名思义: change owner 改变所有者
> 
> 所有者有两类, 一是用户 二是组\(group\)
> 
> 

```Bash
chown qiulin:qiulin_2 hello.c
```

> 改变hello\.c的所有者信息, 所有者是qiulin 所属组别是qiulin\_2
> 
> 如果qiulin qiulin\_2不存在,那么就会报错, chown不会帮你创建用户和组的
> 
> 



# chgrp

> 修改组
> 
> 

和上面的chown差不多, 不需要太过于死记硬背\.

```Bash
chgrp qiulin_2 hello.c
ls -l hello.c

```



# 链接

## 硬链接

```Bash
ln hello.c ../hello_link.c
```

不加任何参数就是硬链接\. 两个文件共享同一个文件的内容\. 通过inode来绑定\.

查看inode代码:

```Bash
ls -i
```

限制条件: 

1. 只能是文件, 防止目录被死循环调用

2. 删除一个,不影响另外的, 除非全部删除

3. 不能跨文件系统  //这个还暂时有疑问, 暂时不深究这个



## 软连接

```Bash
ls -s hello.c hello_2.c
```

软链接也称符号链接\(symbolic\)\. inode不是一样的, 删除了源文件也就会失去效果,"断链"\.

它可以链接目录\. 

> 可以把它理解为windows下的快捷方式\. 一旦源文件被删除,快捷方式也不会被打开了\.
> 
>
