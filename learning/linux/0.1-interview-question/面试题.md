# 1、Linux操作系统下各路径存放什么文件？（`usr/dev/opt/etc/home/bin/media`）

## 答: 
1. `/usr`: 各类软件的存放地址. 存放各类程序和配置. 比如终端命令(`/usr/bin`), 头文件(`/usr/include`), 库文件(`/usr/lib`)
2. `/dev`: 各类设备文件, 常用的有鼠标, 键盘, 硬盘,终端
3. `/opt`: 统一存放第三方软件的. 比起一般程序, 可能需要存放到 `/usr` `/lib` `/bin` 下, 也可以统一存放到`/opt`文件夹下, 这样方便后续的删除.
4. `/etc`: 各类配置文件. 最常见的就是`/etc/profile`可以配置系统的环境变量.还有各类软件的配置, 常见的: `apt` , 还有一些系统级别的配置: `bluetooth` `kernel` 蓝牙 内核的配置
5. `/home`: 用户的家目录. 存放各个用户的目录. 用户自己的文件 配置 软件都可以放在这个文件夹下. 我常用的就是`/home/roly` `~/.bashrc` 
6. `/bin`: 各类二进制可执行程序/命令的存放目录. 常用的各种命令`ls` `cp` `mv` `cp` `rm` 都是放在这里. 当然在现代Linux系统下, `/bin` 目录都重定向到了`/usr/lib`目录下了.
7. `media`: 各类媒介, U盘 SD卡 移动硬盘等, 都会自动挂载到这个上面去. 还有一个`/mnt`文件夹, 这个是需要管理员手动去挂载上去的. 我觉得它俩的区别就是一个自动 一个手动.

## AI建议答案:
```markdown
/usr：存放大量用户空间程序及其共享数据。例如 /usr/bin 存放普通命令，/usr/lib 存放库，/usr/include 存放头文件。
/dev：存放设备文件，也就是访问设备的接口。例如磁盘、终端等设备对应的设备文件。
/opt：主要用于安装附加的第三方软件，通常可以把一个软件相关的文件集中放在 /opt/软件名 下。opt 可以记成 optional。
/etc：主要存放系统级和软件的配置文件。例如 /etc/profile、APT 的配置等。可以把 /etc 和“系统配置”关联起来记。
/home：普通用户的家目录。例如用户 roly 的家目录通常是 /home/roly，用户自己的文件和个人配置通常放在这里。root 的家目录通常是 /root。
/bin：传统上存放基本的用户命令，例如 ls、cp、mv、rm。现代很多 Linux 发行版采用 merged /usr，因此 /bin 常常是指向 /usr/bin 的符号链接。
/media：主要作为 U 盘、SD 卡、移动硬盘等可移动介质的挂载位置，桌面 Linux 经常自动在这里创建挂载点。/mnt 则主要作为管理员临时挂载文件系统的位置。
```

# 2、Linux 操作指令：
- 查看文件前5行
- 查看文件后5行 且实时查看
- 搜索文件是否包含特定内容
- 压缩与解压文件
- 创建软连接与硬链接
- 如何修改某网卡的ip地址

## 答: 
1. `head -5 main.c`
2. `tail -5 -f main.c`
3. `grep -e "main()" -f main.c` 查看`main.c`文件内是否有`main()`字符串
4. `tar` 命令: 压缩: `tar -cvf main.tar main.c hello.c`; 解压: `tar -xvf main.tar`
5. `ln` 命令: 软链接: `ln -s target.c main.c` 给main.c文件创建软链接文件target.c; 硬链接: `ln target.c main.c`
6. `nmcli connection modify`

例子: 修改名字为`ssh_ip`ip地址
`nmcli connection show`
`nmcli connection modify ssh_ip ipv4.address 192.168.1.100/24 ipv4.gateway 192.168.1.1 ipv4.dns 8.8.8.8 ipv4.method manual`

`192.168.*.*` 这是`ipv4`规定的私有网络ip, 也就是局域网的ip地址.
子网掩码的作用就是告诉你前几位是网络地址, 后几位是主机位

网关就是负责去和外面对接的, 默认就是192.168.1.1; 如果是自己局域网内的互相访问, 就不需要用到网关. 如果是局域网之外的, 就会把数据交给网关, 由网关来负责外面的联络

`dns` 域名解析, `8.8.8.8`是谷歌提供的dns服务器地址, 非常好记. cloudflare也有`1.1.1.1`. 所以这个无所谓. 知道几个常用的就行.

## AI推荐答案
```markdown
1. 查看文件前 5 行
   head -n 5 main.c

2. 查看文件后 5 行，并实时跟踪
   tail -n 5 -f main.c

3. 搜索文件是否包含特定内容
   grep "main()" main.c

4. 压缩与解压文件
   压缩：
   tar -czvf main.tar.gz main.c hello.c

   解压：
   tar -xzvf main.tar.gz

5. 创建软链接和硬链接
   软链接：
   ln -s main.c target.c

   硬链接：
   ln main.c target.c

6. 修改网络连接的 IPv4 地址
   nmcli connection show

   nmcli connection modify ssh_ip \
       ipv4.addresses 192.168.1.100/24 \
       ipv4.gateway 192.168.1.1 \
       ipv4.dns 8.8.8.8 \
       ipv4.method manual

   nmcli connection up ssh_ip
```

# 3、软连接与硬链接的区别
## 答:
1. 软链接, 不同的inode, 一旦源文件被移除, 就会"断链". 可以链接目录.
2. 硬链接, 相同的inode, 即使源文件被移除, 链接文件也不会受影响, 内容还是可以被访问到. 不能链接目录.
## AI答案
```markdown
- **软链接**：软链接是一个独立文件，有自己的 inode，里面保存目标文件的路径。目标文件被删除后，软链接会变成悬空链接。软链接可以链接目录，也可以跨文件系统。
    
- **硬链接**：硬链接和原文件名指向同一个 inode，相当于给同一个文件增加一个名字。删除其中一个文件名，不影响通过其他硬链接访问文件。硬链接通常不能链接目录，也不能跨文件系统。
```

# 4、环境变量有什么用？什么时候需要使用到环境变量？如何配置环境变量？
## 答:
环境变量的作用: 存放系统配置文件 程序/命令搜索路径
什么时候用到环境变量: 执行命令 调用动态库文件
配置环境变量: 临时配置-export 变量=值. 永久配置: 用户级别-~/.bashrc; 系统级别: /etc/profile

## AI答案
```markdown
环境变量是操作系统提供给进程的一组 变量名=值 的运行环境信息，程序可以通过环境变量获取配置并改变自己的行为。
常见场景包括：通过 PATH 指定命令搜索路径，通过 LD_LIBRARY_PATH 指定额外的动态库搜索路径等。
临时配置可以使用：
export 变量名=值
例如：
export PATH="$PATH:/home/robin/bin"
用户级的长期配置可以写入 ~/.bashrc，系统级配置可以根据登录环境写入 /etc/profile 等配置文件。
```

# 5、现有文件main.c 1.c 1.h 2.c 2.h 五个文件，编写一个Makefile将五个文件编译成main.exe  
要求使用符号优化写法，并增加clean指令

## 答:
```Makefile
CC = gcc
TARGET = main.exe
OBJS = main.o 1.o 2.o
$(TARGET): main.o 1.o 2.o 1.h 2.h
	$(CC) $(OBJS) -o $@
%.o: %.c
	$(CC) -c $< -o $@
	
.PHONY: clean

clean: 
	rm -f *.o *.exe

```
