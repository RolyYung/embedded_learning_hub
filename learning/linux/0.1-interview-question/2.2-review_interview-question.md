
### 8分题
1. 进程与线程的区别，以及实际什么场景运用它们  
```
进程: 独立的虚拟地址空间, 有父子关系, 资源分配的最小单位
线程: 共享进程的内存空间, 没有父子关系, 任务调度的最小单位. 

应用场景: 没有共享的资源且不希望被其他任务中断 打扰, 就用进程. 网页浏览器, 各自保存浏览数据等, 不受其他网页影响
有共享资源需要被操作, 其他线程的崩溃可能会引发整个线程的崩溃. 服务器接收不同用户的请求.
```
1. fork 函数如何使用？为何fork的返回值如此设计？  
```
一次调用, 两次执行.
返回值有三种, 失败: <0. 成功: =0: 子进程. >0: 父进程, 
方便做程序判断;
父进程接收子进程id,方便进行资源回收操作.
```
1. 什么是虚拟地址？有什么作用？
```
进程执行使用的记录内存地址, 使用的是虚拟地址.
作用: 进程间物理内存的访问隔离, 方便做内存动态管理.
```

### 13分题
1. 进程间通信有哪些？各有哪些特点？
```
无名管道(pipe): 亲缘间进程通信, 数据单方向流动,读写端需要同时引用, 不然就会被回收.
有名管道(fifo): 不同进程间通信, 有专门的管道文件可以被访问,完成后记得把文件unlink掉,避免造成资源浪费
信号(signal): 内核执行, 终端 程序 内核都可以发送信号, 通常用于事件的发送. 中断 暂停 终止等
消息队列(msgget,msgsnd,msgrcv): 消息类型(type) 和 消息正文(text)组成
共享内存(shmget, shmat,shmdt,shmctl): 内核开辟一个共同的内存空间供不同进程访问.
信号量集(semget): 用于控制资源的使用, 通过P操作, V操作来申请、释放资源.
```

### 15分题
1. 线程同步实现方法及代码编写，两个线程交替打印AB。（应用层常考）  
```C

sem_t sem1, sem2;

void * thread_1(void * arg){
	for(int i=0; i<10;i++){
		sem_wait(&sem1);
		printf("A");
		sem_post(&sem2);
	}
	return NULL;
}

void * thread_2(void * arg){
	for(int i=0; i<10; i++){
		sem_wait(&sem2);
		printf("B");
		sem_post(&sem1);
	}
	return NULL;
}
int main(){

	sem_init(&sem1, 0,1);
	sem_init(&sem2, 0,0);
	
	pthread_t tid1,tid2;
	pthread_create(&tid1, NULL, thread_1, NULL);
	pthread_create(&tid2, NULL, thread_2, NULL);
	
	pthread_join(tid1, NULL);
	pthread_join(tid2, NULL);
	
	sem_destroy(&sem1);
	sem_destroy(&sem2);
	return 0;
}
```
1. 死锁是如何产生的？怎么避免死锁的产生  
```
死锁一般产生在多个资源锁互相竞争导致永远不能等待到资源锁的解开.
避免: 多个资源锁在尽量按照统一的顺序来进行调用. A->B->C. 而不是A->B B->A
尽量少同时调用多个资源锁
资源锁用完后, 尽早的释放掉.
```
1. 简述线程池的概念与作用
```
线程池就是预先创建多个线程处理相同任务, 不会重复创建 删除.
没有任务时就等待处理.
作用: 避免额外的创建  删除开销
规定了并发量
按照任务队列依次执行.
```
