
### 8分题
1. 进程与线程的区别，以及实际什么场景运用它们  
```
进程: 独立的虚拟地址空间, 有父子关系, 资源分配的最小单位
线程: 共享进程的内存空间, 没有父子关系, 任务调度的最小单位. 

应用场景: 没有共享的资源且不希望被其他任务中断 打扰, 就用进程. 网页浏览器, 各自保存浏览数据等, 不受其他网页影响
有共享资源需要被操作, 其他线程的崩溃可能会引发整个线程的崩溃. 服务器接收不同用户的请求.
```
1. fork 函数如何使用？为何fork的返回值如此设计？  
```
一次调用, 两次执行.
返回值有三种, 失败: <0. 成功: =0: 子进程. >0: 父进程, 
方便做程序判断;
父进程接收子进程id,方便进行资源回收操作.
```
1. 什么是虚拟地址？有什么作用？
```
进程执行使用的记录内存地址, 使用的是虚拟地址.
作用: 进程间物理内存的访问隔离, 方便做内存动态管理.
```

### 10分题
1. 简述写实拷贝技术 与 计数技术  
```
fork后的父子进程,在最开始都是映射都相同的物理内存,节省空间. 直到有一方修改了其内存存储值后, 拷贝一份出来.
计数技术: 内核对资源的实际调用会用计数, 如果计数为零, 会自动回收.`unlink`函数的作用也是做文件计数的切断,方便后面的回收.
```
1. 为何进程需要有僵尸态？描述几种僵死子进程回收的方法。  
```
僵尸态: 死亡但未回收. 就像人一样, 死了还要到公安局注销身份证等社会信息
回收: wait() wait_pid()资源回收函数.
父进程退出, 由系统级别回收进程进行回收.
SIG_CHLD信号接收
```
1. 线程的属性有哪些？他们有什么区别？如何设置线程的属性？  
```
常见的就是结合态 分离态. 还可以设置私有栈大小等等. 通过pthread_attr_t, pthread_attr_init等函数进行设置.
结合态: 需要被其他线程进行回收, 可以回收退出状态
分离态: 不会通知主线程, 进程退出, 由系统自动回收

pthread_create()第二个参数设置
也可以通过pthread的一些函数如: pthread_detach()来设置
```
1. 线程间有哪些资源是共享的？哪些资源是独有的？
```
全局变量, 静态变量, 已经打开的文件描述符,堆区
私有站, 线程ID, 寄存器上下文等.
```
