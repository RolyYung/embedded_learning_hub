
1、Linux操作系统下各路径存放什么文件？（usr/dev/opt/etc/home/bin/media）
答: `/usr`目录就是存放给各个用户使用的程序, 库之类的. 比如动态库`/usr/lib` `/usr/bin`  `/usr/src`存放了一些进程的头文库
`dev` 设备的意思, 存放各类设备(鼠标 键盘 终端等)
`/opt` 存放第三方软件的地方, 有些软件可能存放在不同位置, 程序存放在`/bin` 库存放在`lib`. 可以存放到`/opt` 方便统一管理
`/etc` 各类配置文件, 最常用的就是`/etc/profile`文件. 就是存放环境变量配置
`/home` 就是用户的家目录, 存放各个用户的配置和文件
`bin` 存放各类可执行文件, 我们常用的`ls` `mv` `cp`等都是存放在这里. 
`media` 媒介文件夹. 一般U盘 SD卡 移动硬盘 都是自动加载到这里. 
`mnt` 这个可以, 但需要手动设置

3、软连接与硬链接的区别
区别: 软链接有各自的`inode` 硬链接共享同一个`inode`
软链接可以跨系统文件 可以链接目录 源文件被删除后 就访问不了了
硬链接不能跨系统文件, 不能链接目录, 但删除文件不会影响其他文件.

5、现有文件main.c 1.c 1.h 2.c 2.h 五个文件，编写一个Makefile将五个文件编译成main.exe  
要求使用符号优化写法，并增加clean指令

```Makefile
TARGET = main.exe
CFLAGS = -Wall -std=11
CC = gcc
OBJS = 1.o 2.o main.o

$(TAGGET): $(OBJS)
	$(CC)  $(OBJS) -o $@
	
1.o: 1.h
2.o: 2.h

%.o: %.c
	$(CC) -c $(CFLAGS) $< -o $@
	
.PHONY: clean

clean: 
	rm -f $(OBJS) $(TARGET)
```

6、GDB调试一般用于排查什么问题？GDB的调试流程？
答: 排查程序运行过程中错误, 段错误, 访问越界, 访问空指针 野指针等问题.
调试流程:
增加调试信息 `gcc -g main.c -o main`
gdb运行: `gdb main`
查看代码: `list`
增加断点: `break 10` 第十行增加断点
开始执行: `run`
打印变量值: `print a`
查看调用栈: `bt`
查看断点信息: `info breakpoint`
跳过这个断点: `continue`
执行下一步且跳过函数: `next`
执行下一步且进入函数: `step`
退出: `quit`

7、段错误是什么意思？产生段错误的原因有哪些？
段错误: 分段错误, 访问了不属于程序/进程的地址. 
比如访问了野指针, 被释放的指针, 访问数组越界,函数递归调用导致了内存溢出等等

8、标准IO与文件IO的区别有哪些？
答: 标准IO是由C语言库函数提供一系列IO函数, `fread, fopen, fwrite, fclose`等, 它在不同的平台下调用不同平台提供的底层调用实现统一且标准的功能. 有统一的缓冲机制, 避免频繁操作底层造成的不必要开销. 针对字节流进行操作.
文件IO在Linux下,就是指的Linux提供的一系列IO函数, 以内核态的形式对硬件底层进行输入与输出`open, read, write`. 针对文件描述符进行操作.适合大块的文件的读写. 

9、标准IO的缓冲区有哪些？作用于哪里？刷新条件有哪些？为什么需要用到缓冲区？
答: 行缓存 全缓存 无缓存. 
行缓存: 作用于stdin stdout这类终端标准输入输出
全缓存: 用于文件的读写操作
无缓存: 主要是stderr
刷新条件: fclose 缓冲区满 fflush手动刷新 程序运行结束 输入输出状态的切换
行缓存还有一点就是遇到换行就刷新

为什么: 避免频繁的用户态 内核态的切换,造成系统不必要的开销.

10、动态库和静态库的区别？各有什么好处？
静态库是在链接阶段 直接接入到程序文本中去, 不会存在程序外的依赖,但会造成程序占用空间增加的问题. 静态库一旦有修改,就需要重新编译部署, Linux系统下以.a后缀结尾
动态库不会接入到程序文本中去, 执行时需要去库中查找, 有依赖关系, 一旦库中没有,执行后会报错. 但这样可以节省不必要的重复代码, 功能更新也不需要重新编译.
