# 用户指令

# useradd

```Bash
useradd [选项] [用户名]
```

> 通常会用到\-m这个选项, 在创建用户的同时在/home文件夹下创建了对应的用户目录文件夹
> 
> 

useradd不会自动在/home文件夹下创建对应目录, 原因是在服务器管理中, 有些用户不需要存放任何文件,只需要执行某些特定程序\. 所以默认是不创建对应home目录

在ubuntu系统下, adduser命令会自动帮你创建\. 这是这些发行版给的快捷指令, linux原生内核并不支持\.



# su

```Bash
su - [username]
su username
```

> 加上\-会自动切换到具体的/home/\[user\]文件目录下
> 
> 

su: substitute \(代替\) user

如果后面没有用户名, 就会切换到root下\.

非特殊情况, 一般不切换到root下, 有什么命令执行sudo\.

原因: 一旦进入到root下, 执行任何命令就不会受到阻碍, 权限得不到控制, 自己也不易察觉\.

在需要用到root权限时, 用sudo命令会更好\.



# sudo

```Bash
sudo [command]
```

sudo: superuser do

暂时使用root 超级用户的权限执行某些命令



# passwd

```Bash
passwd [username]
```

设置用户的密码, 如果没有用户名就会默认设置当前用户的password

> 一般是跟在useradd 后, 创建用户后需要设置密码, 不然会访问不了这个用户, 因为没有正常的访问权限和密码
> 
>

# userdel

```Bash
userdel -r [username]
```

> userdel 一般需要带\-r选项, 这样会自动删除用户的home 目录以及邮箱等设置\.
> 
> 和useradd一样, 基本的命令只是删除了系统的用户注册, 而用户产生的目录 记录还是会在,带上\-r会删除的更彻底一些\.
> 
> 



# usermod

> user modify 用户修改\. 配合一些选项参数就能改变用户属性, uid, gid, 权限等
> 
> 

```Bash
usermod [-g] name
```

常用 usermod \-g: 修改用户的组\(group\)



# groupadd

> 创建一个新组\. 
> 
> 

```Bash
groupadd name
```

\-g: 如果带这个参数, 就会由用户手动指定组名\.



# groupdel

> 删除组
> 
> 

```Bash
groupdel name
```
