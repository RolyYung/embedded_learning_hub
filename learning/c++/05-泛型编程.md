# 概念
***
编写不再依赖具体数据类型的程序
现实应用: 编写通用算法, (顺序表 链表等具体数据结构, 用一个函数就可以实现同一个算法)

# Template
***
模板: C++支持的新语法. 为泛型编程的实现提供了基础.

## STL
***
`Standard Template Library` 标准模板库

`STL`中包含: 容器(container) 迭代器(iterator) 算法(Algorithm) 适配器 分配器(allocate)

**容器负责存储数据，迭代器负责访问数据，算法负责处理数据。**


# 引用扩展
***
## 万能引用
***
```c++
template <typename T>
void Show(T && i)
{
	cout << i << endl;
}
```
这是c++11标准的万能引用.
万能引用解决的是: 传递的参数可能是左值, 可能是右值的情况下, 通用一个函数, 减少函数重写.

## 引用折叠
***
```c++
void Show(T && i)
```
这段代码就用到了引用折叠, T可能是`int &` 也可能是`int &&` 后面加上`&&` 后就能原封不动的给到传递给i正确的值.
而 T &&  这个就是c++一个固定格式, c++编译器碰到这个格式了就会自动把传入的传输 改成左值 / 右值
在利用引用折叠. 就能原封不动的传值.

## 完美转发
***
`forward`
`std::forward`
用处: 保留原始的参数类型(左值/右值)
在万能引用的情况下, 会把参数都会弄成左值.
而代码
```c++
forward<T>(i) 
```
就能传递原本的i值.


# 智能指针
***
c++ `memory`库的
最开始`auto_ptr` 后面因为功能缺陷被弃用, 现在用会被编译报错

## `unique_ptr`
***
解决了`auto_ptr`的拷贝问题(禁止拷贝), 不能管理数组问题
```c++
unique_ptr<Test> up(new Test);
unique_ptr<Test> up2 = up; // 报错

unique_ptr<Test[]> up3(new Test[5]);

```

## `shared_ptr`
***
通过引用计数来实现多个指针管理一个数据.(强引用计数)

## `weak_ptr`
***
解决`shared_ptr`强引用计数导致的死锁, 内存泄漏问题.
