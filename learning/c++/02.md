# 面向对象编程
***
将一个功能, 一个问题抽象成一个类型 一个工具.
遇到问题, 先找工具, 再利用工具去解决问题.

# 类class
***
```c++
class A {
	int x;
	int y;
}
```

类 是一种数据类型(用户自定义的)
它有成员属性(member attribute)

## public private protected
***
引入了三个关键字
控制类的属性访问权限.
public 就是公开可访问的. 一般就是对外的接口
private 就是私有的, 一般是类属性
protected 是保护的, 一般是用于继承的(还没接触到, 先不深入了.)

默认是private. 

## 构造函数
***
对象创建是自动执行的函数
函数名必须和类名相同。
没有返回值，连 `void` 都不能写。
创建对象时自动调用。
可以重载，写多个不同参数的构造函数。
**保证对象一出生，就处于合理的初始状态。**
```c++
class Point {
public:
	Point(int x, int y){
		m_x = x;
		m_y = y;
	}
	
private:
	int m_x;
	int m_y;
};

Point p(1,2);
```

## 初始化列表
***
**member initializer list**
```c++
class Point {
public:
	Point(int x, int y): m_x(x), m_y(y), m_name("roly")

	}
```
