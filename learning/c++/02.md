# 面向对象编程
***
将一个功能, 一个问题抽象成一个类型 一个工具.
遇到问题, 先找工具, 再利用工具去解决问题.

# 类class
***
```c++
class A {
	int x;
	int y;
}
```

类 是一种数据类型(用户自定义的)
它有成员属性(member attribute)

## public private protected
***
**访问控制符**
`access specifier`

引入了三个关键字
控制类的属性访问权限.
public 就是公开可访问的. 一般就是对外的接口
private 就是私有的, 一般是类属性
protected 是保护的, 一般是用于继承的(还没接触到, 先不深入了.)

默认是private. 

## 构造函数
***
对象创建是自动执行的函数
函数名必须和类名相同。
没有返回值，连 `void` 都不能写。
创建对象时自动调用。
可以重载，写多个不同参数的构造函数。
**保证对象一出生，就处于合理的初始状态。**
```c++
class Point {
public:
	Point(int x, int y){
		m_x = x;
		m_y = y;
	}
	
private:
	int m_x;
	int m_y;
};

Point p(1,2);
```

## 委托构造函数
***
`Delegating constructor`
示例代码:
```c++
class P{
public: 
	P(int a, int b): x(a), y(b)
	{}
	
	P() : P(0,0)
	{}
	
private:
	int x;
	int y;
}
```

从示例代码中也能看出来, 初始化列表要么就是类名, 来调用其他构造函数, 要么就是成员属性.
而委托构造函数, 就是避免重复写代码
是c++11引入的概念.

## 拷贝构造函数
***
`Copy Constructor`

```c++
class P{
public:
	P(int a, int b): x(a), y(b)
	{}
	
	P(const P &other): x(other.x), y(other.y)
	{}
	
private:
	int x;
	int y;
}
```

### 删除拷贝构造函数
***
```c++
P(const P &) = delete;
```
禁止拷贝,也就是不允许有下面的代码
```c++
P p1(1,2);
P p2 = p1;
```

现实用例:
文件对象. 不允许已经打开的文件对象, 进行拷贝构造. 导致同一个文件被不同对象打开了.
**确保资源唯一性**

## 移动构造
***
`Move Constructor`

将旧对象直接接管, 避免多次拷贝导致的内存开销.
拷贝构造: 复制
移动构造: 转移

### move
***
能直观触发移动构造的函数: `move`
全称: `std::move`

作用: 标记一个对象可以被移动.
但并不代表它会被销毁和清空. 
**我允许你搬它的资源, 但具体搬不搬看你自己的代码**
调用move函数, 能够让编译器快速和我写的移动构造函数匹配

## `explicit`
***
`清晰的, 显式的`
也就是必须是准确的构造函数声明,下面代码就会报错:
```c++
P p = 10; // 报错
P p(10); //正常 
```

**禁止编译器自动做隐式类型转换**

## `static`
***
static 关键字在C语言 class中还做了扩展
```c++
class P
{
private:
	int i;
	static int j;
}
```
这里声明了一个静态成员`j`, 只能在类外定义:
```c++
P::j = 10;
```

不能在类中定义.可以在类中修改值
```c++
class P
{
public:
	void Show(){
		j = 10;// 可行
	}
private:
	int i;
	static int j;
}

P::j = 20;

```
静态成员先于对象创建.
如果在对象创建还静态成员还没定义, 就会链接(linker)报错.

静态属于类 不属于具体对象.

## `const`
***
只读成员
```c++
class P
{
public:
	P(int i, int j): i(i), j(j)
	{}
private:
	int i;
	const int j;
}
```

只读成员的初始化, 只能通过初始化列表, 不然就会报错.

只读成员函数
```c++
class P
{
public:
	void Show() const
	{
		i = 10; //报错. this下的成员都不能修改.	
	}
private:
	int i;
	const int j;
}
```

**不能修改this下的成员**
**普通函数默认可能会修改成员, 所以也不能调用普通函数**

## 练习: MyString类实现number转string
***
思路:
```c++
// 判断负数
bool isNeg = number < 0;
// 将数字转为整数
if(isNeg) number = -(number);
// int类型最高是40亿,也就是15位字符
char buf[15]{0}; // 初始为0
// 从低到高, 循环取出数字
// -记录位数i
int i = 0;
// 循环
do{
buf[i] = '0' + (number % 10);
number /= 10;
i++;
}while(number > 0);

// 末尾增加负数'-'
if(isNeg) buf[i] = '-';

// 写一个反转函数
Reverse(buf);

// 反转函数
void Reverse(char * buf)
{
	int length = strlen(buf);
	for(int i = 0; i<(length - 1) / 2; i++)
	{
		char temp = buf[i];
		buf[i] = buf[length - 1 - i];
		buf[length - 1 - i] = temp;
	}
}
```
