```
可能会导致vector容器迭代器失效的操作有insert（插入元素）、erase（删除元素）、push_back（尾插元素）、resize（重置容器大小）、assign(重新赋值)
```

错误点: assign, 以为只是对某个元素的重新, 不改变容器. 实际是清空容器, 会改变容器大小, 也会改变容器内存地址,根据传的值确定.

2/
```
在同一个类中，可以定义重载的成员函数 void f(int& anInt);和void f(int&& anInt);和void f(const int& anInt);
```
对. 
错误点: `int& anInt` `const int& anInt` 一个是左值, 一个是常量左值, c++会识别的, 符合"不同参数"的重载要求.
