# 友元
***
```c++
friend
```
关键字
友元: 这个函数/类 不属于当前类, 但可以访问它的私有 保护成员.
## 友元函数
***
定义在类外的函数.
使用场景很少. 主要是笔试 面试题.
算法类有时候会涉及到
```c++
class A 
{
friend void Show(A &a);
private:
	int m_x;
	int m_y;
}

void Show(A &a)
{
	cout << a.m_x << a.m_y << endl;
}
```

**友元的设置, 不受访问控制符的限制. 声明在哪里都可以.**

## 友元类
***
可以互相访问各自的私有 保护成员.
在友元类的相互访问中有一个坑:

A.h:
```c++
#include "B.h"
class A {
private: 
	int m_x;
	int m_y;
	friend class B;
}
```

B.h:
```c++
#include "A.h"
class B{
private:
	int m_a;
	int m_b;
	friend class A;
}
```

头文件会相互依赖, 导致编译报错.
这种情况下, 头文件不要`include`头文件, 而是在头文件进行`前向声明`

# 运算符重载
***
`operator overloading`
**把符号当函数使用**

## 成员函数的运算符重载
***
`C = A + B`
A: 第一个操作数
+: 操作符
B: 第二个操作数
C: 结果.

在成员函数的运算符重载时:
A: this.
B: 第一个参数
C: 返回值
+: 运算符重载(函数)

### 例子: +的运算符重载. Point
```c++
class Point
{
public: 
	Point(int x, int y) : m_x(x) , m_y(y)
	{
		
	}
	
	Point operator+(const Point &p) const
	{
		int x = m_x + p.m_x;
		int y = m_y + p.m_y;
		return Point(x, y);
	}
private:
	int m_x;
	int m_y;

};
```

### 例子: `++`
***
自增运算符. 
因为其有两种形式: 前置 后置
所以定义有区别:
```c++
class A
{
public: 
	// 前置运算符重载
	A operator++()
	{
		++m_x;
		return *this;
	}
	
	// 后置运算符重载
	A operator++(int)
	{
		A temp(m_x);
		++m_x;
		return temp;	
	}
private:
	int m_x;
}


```

## 全局运算符重载
***
`C = A + B`
A: 第一个操作数
+: 操作符
B: 第二个操作数
C: 结果.

A: 第一个参数
B: 第二个参数
+: 函数
C: 返回值

**一般都需要配合友元才能有效, 因为会操作内部成员**

# 问题: 类的定义中如果一个函数都没写, 默认自带的会有几个函数?
***
默认会有这几个函数:
```c++
A();                         // 默认构造
A(const A&);                 // 拷贝构造
A(A&&);                      // 移动构造
A& operator=(const A&);      // 拷贝赋值
A& operator=(A&&);           // 移动赋值
~A();                        // 析构
```
但只有在使用的时候才会生成. 所以一般就是拥有一个"默认构造"


# 内联函数
***
`inline` 关键字

原理: 解决函数调用的效率问题.
一般不超过十行. 不允许递归 循环 switch.
类内定义的一般是内联函数
类外的需要加inline关键字.

## 与宏的区别
***
宏: 预处理, 没有类型判断 语法判断
内联: 编译器处理, 比宏更安全.
