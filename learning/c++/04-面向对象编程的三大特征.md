# 继承
***
## 为什么需要继承
***
示例: 动物管理系统
动物里有猫 狗.
猫狗各有特点 但也有相同的地方.(眼睛 鼻子 耳朵 腿)(跑 跳 坐 睡觉)
生物界的分类: 界门纲目科属种, 就是最好的分类与继承. 
不同的对象被分成不同的类.

c++代码:
```c++
#include <iostream>
#include <string>
using namespace std;

// 父类：动物
class Animal {
public:
    string name;

    void eat() {
        cout << name << " 正在吃饭" << endl;
    }

    virtual void sound() {
        cout << "动物发出声音" << endl;
    }

    virtual ~Animal() = default;
};

// 子类：猫
class Cat : public Animal {
public:
    void sound() override {
        cout << "喵喵喵" << endl;
    }

    void catchMouse() {
        cout << "猫正在抓老鼠" << endl;
    }
};

int main() {
    Cat cat;

    cat.name = "小橘";
    cat.eat();
    cat.sound();
    cat.catchMouse();

    return 0;
}
```

## 继承的核心机制
***
### 准确概念
***
1. 基类(Base Class): 被继承的类
2. 派生类(Derived Class): 继承其他类的类

### 继承后发生了什么
***
当创建`Cat cat`后, 会先创建一个`Animal`对象.
![[file-20261104112009117.png]]
每个Cat对象都会有一个Animal基类子对象.

成员函数通常以代码形式,不会在每个对象内复制.

### 三种继承方式
***
public: 基类所有的成员都继承, 也保留了访问域.
protected: 基类的public protected成员全部都放入子类的protected. private还是放在private.
private: 就是全部成员转到private. 

### 继承与多态的关系
***
当基类有虚函数, 子类有实现时
根据对象的实际类型, 调用具体的版本.
叫做: 运行时多态.



```c++
class A : B
{
public:
	A()
	{}
private:
	int m_x;
	int m_y;
}
```

# 多态
***
**同一个接口, 因为对象类型的不同, 产生不同的行为.**

## c++的两种多态
***
### 静态多态
函数重载 运算符重载等.
也叫编译时多态

### 动态多态
虚函数重写. 继承.
也叫运行时多态
