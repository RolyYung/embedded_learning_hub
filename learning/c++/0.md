(1)C++ 引用与指针的区别
(2)如何实现多态及应用场景
(3)C++11 的特性
(4)深拷贝和浅拷贝区别
(5)智能指针有哪些，各自有什么优缺点
(6)STL 容器内容，及各自的优缺点

答:
(1):
```
C++ 中，引用可以理解为变量的别名，指针则是存储变量地址的对象。

它们主要有以下区别：

1. **初始化**：引用必须在定义时初始化，指针可以不初始化。
2. **指向关系**：引用一旦绑定对象，就不能重新绑定；指针可以改变指向。
3. **空值**：指针可以为 `nullptr`，引用正常使用时必须绑定有效对象。
4. **使用方式**：引用可以直接操作对象，指针通常需要解引用。
5. **指针运算**：指针支持地址运算，引用不支持。

引用和指针都可以避免传递大型对象时产生不必要的拷贝。

C++11 还引入了右值引用，主要用于支持移动语义和完美转发。

**实际开发中**，函数参数通常优先考虑引用，需要表示空值或改变指向时使用指针。

引用通常用于明确需要对象的场景，指针适合需要判空、改变指向等场景。
```

(2):
```
C++ 多态分为静态多态和动态多态。

1. **静态多态（编译时多态）**：在编译阶段确定具体调用。主要通过函数重载、运算符重载和模板实现。典型应用场景是泛型编程，例如 STL。
    
2. **动态多态（运行时多态）**：通过继承、虚函数以及基类指针或引用实现。在运行时根据对象的实际类型调用对应的虚函数。
    

**应用场景**：例如动物类定义虚函数 `sound()`，猫和狗分别重写。通过 `Animal*` 调用 `sound()`，就能根据实际对象执行不同的行为。

动态多态常用于接口设计、插件系统等需要统一接口处理不同对象的场景。
```


(3)
```
C++11 是 C++ 的一次重大更新，引入了许多新特性，我主要从以下几个方面理解：

1. **类型推导**：引入 `auto`、`decltype`，简化类型声明。
    
2. **智能指针**：引入 `unique_ptr`、`shared_ptr`、`weak_ptr`，方便管理动态内存，减少内存泄漏风险。
    
3. **移动语义**：引入右值引用、移动构造、移动赋值，减少不必要的对象拷贝，提高性能。
    
4. **完美转发**：通过万能引用和 `std::forward`，保留参数的左值、右值属性。
    
5. **Lambda 表达式**：可以定义匿名函数，常用于 STL 算法和回调函数。
    
6. **语法增强**：支持范围 `for` 循环、统一初始化 `{}`、`nullptr`、`constexpr` 等。
    
7. **并发编程**：引入 `std::thread`、`std::mutex`、`std::atomic` 等多线程工具。
    

其中，我认为**智能指针、移动语义和 Lambda 表达式**是实际开发中比较重要的特性。
```

(3)
```
C++ 中，深拷贝和浅拷贝的主要区别在于如何处理对象内部的指针资源。

1. **浅拷贝**：直接复制对象的成员值。如果包含指针成员，复制的是指针地址，两个对象会指向同一块内存。
    
2. **深拷贝**：对需要独立拥有的动态资源重新分配内存，并复制资源内容，使两个对象拥有独立的数据。
    

**应用场景**：当类拥有动态分配的内存时，通常需要考虑深拷贝。

**注意事项**：浅拷贝可能导致数据相互影响、重复释放内存等问题。深拷贝可以实现资源独立管理。
```

(4)
```
C++ 常见智能指针有四种：

1. **auto_ptr**：早期智能指针，拷贝会转移所有权，使原指针失效。不支持数组，C++11 已弃用，C++17 已移除。
    
2. **unique_ptr**：独占资源所有权，禁止拷贝，支持移动语义，也支持动态数组。优点是开销小，缺点是不能共享所有权。
    
3. **shared_ptr**：通过引用计数实现资源共享，当最后一个拥有者销毁时释放资源。优点是支持共享所有权，缺点是存在计数管理开销和循环引用风险。
    
4. **weak_ptr**：配合 shared_ptr 使用，不增加强引用计数，可以通过 lock() 检查对象是否仍然存在并获取临时所有权。常用于解决循环引用问题。
    

**实际开发中**，优先使用 unique_ptr，需要共享所有权时使用 shared_ptr，存在非拥有关系时使用 weak_ptr。
```

(5)
```
STL 常见容器可以分为三类：

**1. 顺序容器**

- `vector`：动态数组，内存连续，随机访问快，尾部插入高效，但中间插入删除较慢。
    
- `list`：双向链表，已知位置的插入删除为 O(1)，但不支持随机访问，额外指针开销较大。
    
- `deque`：双端队列，支持随机访问和两端高效插入删除，但内存通常不连续。
    

**2. 关联容器**

- `map`：通常基于红黑树，键有序且唯一，查找、插入、删除为 O(log n)。
    
- `set`：类似 map，只保存唯一键，自动排序。
    
- `unordered_map`：基于哈希表，平均查找效率为 O(1)，但元素无序。
    

**3. 容器适配器**

- `stack`：栈，后进先出。
    
- `queue`：队列，先进先出。
    
- `priority_queue`：优先队列，优先取出优先级最高的元素。
    

**实际开发中**，一般优先考虑 vector；需要有序查找使用 map，需要快速键值查找考虑 unordered_map。
```
