# 几种常见排序

# 直接插入排序\(Insertion Sort\)

> 数组为例: 每个数字拎出来与已经排序好的数组比较, 找到合适的插入位置,进行插入\.
> 
> 

示意图:

![insert \(1\)\.png](图片和附件/insert%20%281%29.png)

代码:

```C
for(int i = 0; i<len;i++){
    int temp = arr[i];
    int j = i;
    while(j >0 && arr[j-1] > temp){
        arr[j] = arr[j-1];
        --j;
    }
    arr[j] = temp;
}
```



# 简单选择排序\(Selection Sort\)

> 不断地在剩下的乱序队伍里，挑出最小（或最大）的那个人，站到前面来。
> 
> 

示意图:

![Selection Sort\.png](图片和附件/Selection%20Sort.png)

代码: 

```Java
// 简单选择排序函数
void selectionSort(int arr[], int n) {
    // 外层循环：确定每一次要填充的位置 i
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i; // 假设当前未排序区的第一个元素就是最小的

        // 内层循环：在未排序区 [i+1 ... n-1] 中寻找真正的最小值
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j; // 更新最小值的下标
            }
        }

        // 如果找到的最小值不在当前位置 i，就交换它们
        if (minIndex != i) {
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }
}
```



# 快速排序\(Quick Sort\)

> 设定一个key值, 分而治之\. 左边是比key小的, 右边是比key大\. 然后左右两边继续这么操作, 直到分成最小的元素单元\. 最后就是一个完整的有序排列\.
> 
>
