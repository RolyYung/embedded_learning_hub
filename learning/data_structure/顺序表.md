# 顺序表

# 定义

> 顺序表 解决了数组的两个问题, 1\. 不知道数组的有效长度 2\. 可以避免越界
> 
> 所以顺序表的结构体 成员有 1\. arr\[\] 2\. size 3\. index
> 
> 

# 代码实现

## 结构体定义

```C
#define MAX 100 // 界定顺序表最大的长度
#define EXPAND_SIZE 10 // 后续扩容以10个元素单位扩容

typedef int DataType

typedef struct SeqList{
    DataType * data;
    int size;
    int index;
}Seq;
```



## 初始化顺序表

```C
Seq * init_seqlist(){
    Seq * seq = (Seq *)malloc(sizeof(Seq));
    if(seq == NULL){
        return NULL;
    }
    DataType * arr = (DateType *)malloc(sizeof(Datatype) * MAX);
    if(arr == NULL){
        free(seq);
        return NULL;
    }
    seq->data = arr;
    seq->size = MAX;
    seq->index = 0;
    
    return seq;
}
```



## 判断是否为空顺序表

```C
int is_empty_seq(Seq * seq){
    if(seq == NULL) return 0;
    return seq->index == 0 ? 1 : 0;
}
```



## 判断是否为满顺序表

```C
int is_full_seq(Seq * seq){
    if(seq==NULL) return 0;
    return seq->size == seq->index ? 1 : 0;
}
```



## 释放顺序表

```C
void release_seqlist(Seq * seq){
    if(seq == NULL) return;
    free(seq->data);
    free(seq);
    return ;
}
```



## 尾插法增加数据

```C
int push_back(Seq * seq, DataType value){
    if(is_full_seq(seq)){
        return -1;
    }
    
    seq->data[seq->index++] = value;
    return 0;
}
```



## 尾删法删除数据

```C
int pop_back(Seq * seq){
    if(is_empty_seq(seq)){
        return -1;
    }
    
    seq->index--;
    return 0;
}
```



## 删除指定数字

```C
int delete_num(Seq * seq, DataType val){
    if(is_empty_seq(seq)){
        return -1;
    }
    int i = 0;
    for(int j=0;j<seq->index; ++j){
        if(seq->data[j] != val){
            seq->data[i++] = seq->data[j];
        }
    }
    seq->index = i;
    return 0
}
```
