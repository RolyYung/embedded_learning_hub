## 开放地址法

> 使用数组保存的哈希表, 如果碰到哈希冲突, 会依次找到适合的索引位置填入数据\.
> 
> 实现方法比较简单, 但容易出冲突\.
> 
> 

## 链地址法\(拉链法\)

> 使用链表存储, 表内只要存放具体的链表首地址即可\. 后续有冲突 可以用头插法 或者顺序插入\.
> 
> 头插法实现比较简单, 目前暂时使用头插法来实现\.
>

# 开放地址法的实现

## 原理

> 先用除留取余法 算到对应的索引值, 如果发生哈希冲突, 就依次往后找, 直到找到空位, 然后填入\.如果到尾巴了就从头开始继续\.
> 
>

## 代码实现

### 创建结构体

```C
#define MAX 10 // 哈希表最大长度
#define NULL_KEY -1 // 默认空值为-1

typedef struct Node{
    int *arr; // 存放数据的数组
    int index; // 当前哈希表存放了多少数据
}HashTable;
```



### 哈希表初始化/创建哈希表

```C
HashTable * create_hashtable(){
    HashTable * h = (HashTable *)malloc(sizeof(HashTable));
    if(h == NULL){
        return NULL;
    }
    int * arr = (int *)malloc(sizeof(int) * MAX);
    if(arr == NULL){
        free(h);
        return NULL;
    }
    h->arr = arr;
    memset(h->arr, -1, sizeof(int)*MAX);
    h->index = 0;
    return h;
}
```



### 判断哈希表是否已满

```C
int is_full_hashtable(HashTable * h){
    if(h == NULL){
        return -1;
    }
    return h->index == MAX ? 1 : 0;
}
```



### 插入数据

```C
int insert_hashtable(HashTable * h, int val){
    if(is_full_hashtable(h)){

}
```

### 扩展问题\- malloc calloc 后的free问题

malloc calloc后, 都是返回给你申请空间的首地址\.

但在内部实现中, 会有一个类似内部管理器的东西, 当你每次申请的时候 都会记录你申请空间的一些信息:

内存地址 内存大小等等\. 等到你调用free时, 就能释放对应的空间\.

所以你malloc了一个p, 只会对p\+1, 那么free\(p\)的操作就会很危险, 行为会未知\.



# 链地址法的实现

## 原理

> 哈希表数组的每个空间, 存放一个链表, 存放的是链表的首地址\. 遇到冲突的, 直接插入到链表中去\. 
> 
> 

这里的实现用 头插法\. 后面升级可以用顺序插入\.

![mergesort \(4\)\.png](图片和附件/mergesort%20%284%29.png)



## 代码实现

### 创建结构体

```C
#define MAX 7

typedef struct n{
    int data;
    struct n * next;
}Node;

typedef struct hashtable{
    Node ** list;
}HashTable;
```



### 哈希表初始化

```C
HashTable * create_hashtable(){
    HashTable * h = (HashTable *)malloc(sizeof(HashTable));
    if(h == NULL){
        return NULL;
    }
    Node ** list = (Node **)calloc(MAX, sizeof(Node *));
    if(list == NULL){
        free(h);
        return NULL;
    }
    h->list = list;
    return h;
}
```



### 插入数据

```C
int insert_hashtable(HashTable * h, int val){
    if(h == NULL){
        return -1;
    }
    
    Node * node = (Node *)malloc(sizeof(Node));
    if(node == NULL){
        return -1;
    }
    int index = val % MAX;
    node->next = list[index];
    node->data = val;
    h->list[index] = node;
    
    return 0;
}
```



### 查找数据

```C
int search_hashtable(HashTable * h, int val){
    if(h == NULL){
        return -1;
    }
    
    int index = val % MAX;
    Node * node = h->list[index];
    int i = 0;
    while(node  != NULL && node->data != val){
        node = node->next;
        i++;
    }
    if(node == NULL){
        return -1;
    }
    printf("loc is : %d, i: %d", index, i);
    return 0;
}
```



### 释放哈希表

```C
void release_hashtable(HashTable * h){
    if(h == NULL){
        return ;
    }
    for(int i = 0; i < MAX; ++i){
       Node * node = h->list[i];
       while(node != NULL){
           Node * nextTemp = node->next;
           free(node);
           node = nextTemp;
       }
       free(node);
    }
    free(h->list);
    free(h);
    return ;
}
```
