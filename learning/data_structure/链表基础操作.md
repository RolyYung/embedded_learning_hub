# 链表基础操作

# 链表初始化 

> 链表节点有两个域, 一个是数据域, 一个是指针域, 指针是指向下一个链表节点
> 
> 注释: 只是单向链表的实现
> 
> 

```C
typedef struct LinkList{
    DataType data;
    struct LinkList * next;
}Node, *NodePointer;
```



# 创建空链表

> 这里实现带头节点的单向链表, 即第一个节点数据域没有值, 指针域指向下一个节点\. 空链表指针域就为NULL
> 
> 

```C
Node * create_empty_linkList(){
    Node * head = (Node *)malloc(sizeof Node);
    if(head == NULL){
        return NULL;
    }
    head->next = NULL;
    return head;
}
```



# 头插法

> 从头节点插入新建的链表节点\.
> 
> 

```C
int push_front(Node * head, DataType value)
{
    if(head == NULL)
    {
        return -1;
    }
    Node * node = (Node *)malloc(sizeof Node);
    if(node == NULL)
    {
        return -1;
    }
    node->data = value;
    node->next = head->next;
    head->next = node;
    return 0;
}
```



# 头删法

> 从头部删除
> 
> 

```C
int pop_front(Node * head){
    if(head == NULL)
    {
        return -1;
    }
    
    if(head->next == NULL)
    {
        return -1;
    }
    
    Node *temp = head->next;
    head->next= head->next->next;
    free(temp);
    
    return 0
}
```



# 打印链表

> 头节点不需要打印,其他的一次打印, 直到最后一个节点
> 
> 

```C
void printf_linkList(Node * head)
{
    if(head == NULL || head->next == NULL)
    {
        return ;
    }
    
    while(head->next != NULL){
        printf("%d", head->next->data);
        head = head->next;
    }
    return ;
}
```



# 尾插法

> 从尾节点插入, 需要先找到尾节点
> 
> 

```C
int push_back(Node * head, Datatype value)
{
    if(head == NULL)
    {
        return -1
    }
    Node * tail = head;
    while(tail->next == NULL)
    {
        tail = tail->next;
    }
    Node * node = (Node *)malloc(sizeof Node);
    if(node == NULL){
        return -1;
    }
    
    node->data = value;
    node->next = NULL;
    tail->next = node;
    return 0;
}
```



# 释放链表

> 从头节点开始 依次释放掉\. 用一个指针保存下一个节点地址\.
> 
> 

```C
void release_linkList(Node * head)
{
    if(head == NULL){
        return;
    }
    Node * temp = head->next;
    while(temp!= NULL)
    {
        free(head);
        head = temp;
        temp = temp->next;
    }
    free(head);
    return ;
}
```
