### 5. volatile

写出 `volatile` 的作用。
```
我的回答: 用volatile定义后的变量, 每次表达式取值 都是需要到实际内存地址取值, 而不是寄存器缓存.
用于易变的变量, 用时候变量的值不是 由于程序引起的修改 而是硬件层面引起, 所以需要这个关键字来建议程序每次取值调用时, 取原始物理内存地址去取, 避免取值错误
```

`volatile` 解决的是**编译器以为这个值不会变”的问题。**

### 6. static

写出 `static` 有哪些作用。
```
1. 变量前加上static声明, 会让变量的生命周期改变, 特别是局部变量(随着程序消亡).
2. 在全局变量和函数前加上, 会让变量和函数变的不可被外部程序访问, 也就是程序内资源.
3. 只会进行一次初始化, 一个作用域被重复被声明, 也不会被影响. 比如函数内声明static int a = 10. a++, 下次调用时 a的值为11, 继续被++
```
