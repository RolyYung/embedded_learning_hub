`int a = 0;`

从简单的变量声明开始。`a` 是一个 `int` 类型的变量。假设它的初始地址是 `0x1000`，这个地址对应的内存中保存的值是 `0`。

如果 `sizeof(int) == 4`，那么 `a` 占用的内存范围可以理解为从 `0x1000` 开始的 4 个字节。

所以我们建立这样的表格：

|变量名|类型|自身地址|值|
|---|---|---|---|
|`a`|`int`|`0x1000`|`0`|

继续声明：

```
const char *str = "hello world";
```

`str` 本身也是一个变量，它自己的类型是 `const char *`。

假设 `str` 自己存放在 `0x2000`，字符串 `"hello world"` 的首地址是 `0x5000`，那么 `str` 中保存的值就是 `0x5000`。

所以表格可以继续写成：

|变量名|类型|自身地址|值|
|---|---|---|---|
|`a`|`int`|`0x1000`|`0`|
|`str`|`const char *`|`0x2000`|`0x5000`|


上面讲到了普通类型(int char), 也提到了指针类型(`char *`). 接下来就是数组(`[]`);
后面每次有新的情况 或者 定义出现. 我们都需要把`&` `sizeof`这个特殊关键字或者符号情况考虑进去, 他们分别的值是多少.
普通的数组定义: `int arr[10] = {0}`;
那么类型应该是`int [10]`; 自身地址是`0x3000`
`sizeof(arr) = 10*sizeof(int)` `&a = 0x3000`
问题: `&arr+1` 是`0x3000+sizeof(int)`还是`0x3000+sizeof(int[10])`呢?
所以这个取值符`&`最后给了一个具体地址, 但实际编译器在处理它的加减法时, 还是会考虑这个地址在注册时候的类型吗? 如果是`0x3001 + 1`呢?


```C
int a = 0;
char *str = "hello";
int arr[10] = {0};
```

| 变量名   | 声明类型       | 自身地址     | 保存的内容      |
| ----- | ---------- | -------- | ---------- |
| `a`   | `int`      | `0x1000` | `0`        |
| `str` | `char *`   | `0x2000` | `0x5000`   |
| `arr` | `int [10]` | `0x3000` | 10 个 `int` |
