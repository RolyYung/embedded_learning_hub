1. epoll并发TCP服务器与TCP客户端
要求: 
```
使用epoll搭建TCP并发服务器，同时监听所有客户端，可同时处理所有客户端数据
使用epoll搭建TCP客户端，从服务器接收数据的同时也可以从终端输入数据，发送给服务器
```
考察: linux网络相关
2. 并行文件搜索工具（线程版）
要求:
```
输入一个文件，递归遍历根目录
（根目录下所有路径存到公共数组中，每个线程依次取出数组里目录遍历，数组处理需要加锁）
使用多个线程并行搜索文件
支持文件名搜索
显示匹配的文件路径
线程安全的输出（输出时需要加锁）
```
考察: linux IO相关
3. 服务器健康检查脚本
要求: 
```
检查系统基本状态并生成报告，根据检查结果按颜色打印。并追加到日志文件中
检查CPU负载
检查内存使用情况
检查磁盘使用率
```
考察: shell 脚本
